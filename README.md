# TUS NLP Laboratory Website

This repository hosts the NLP laboratory website built with Jekyll and the Minimal Mistakes theme.

## Prerequisites

- Ruby 3.1+
- Bundler

## Local Development

1. Install dependencies:

   ```bash
   bundle install
   ```

2. Run the local server:

   ```bash
   bundle exec jekyll serve
   ```

3. Open the local preview URL shown in the terminal.

- `_config.yml`: Jekyll and theme configuration
- `_pages/home.md`: Root landing page
- `assets/css/main.scss`: Theme stylesheet entry point
